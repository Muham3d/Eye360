# Web Views (Admin Panel)

## Purpose
EJS templates for the admin web panel UI.

## Structure
- `layouts/` - Base templates (header, footer, navigation)
- `auth/` - Login pages
- `dashboard/` - Admin dashboard views
- `users/` - User management views
- `sites/` - Site management views
- `patrols/` - Patrol management views
- `incidents/` - Incident reporting views

## Styling
- Uses Tailwind CSS for styling
- Responsive design principles
- Accessibility considerations

## Rules
- Views are presentation only
- No business logic in templates
- Use helpers for complex formatting
